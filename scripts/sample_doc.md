# 企业员工手册（示例）

本手册用于演示企业知识库 RAG 工作台的解析、切分与检索能力。

## 第一章 入职流程

新员工入职需完成以下步骤：提交材料、签订协议、开通账号、参加培训。
入职培训包含公司文化、信息安全与合规三部分，通常在一周内完成。

## 第二章 考勤与休假

员工实行标准工时制，每日工作八小时。年假按司龄递增，最高十五天。
病假需提供医疗机构证明，事假应提前申请并由主管审批。

## 第三章 核心数据字段说明

以下是人事系统核心表的字段定义，属于半结构化内容，应被保护式切分保留：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| employee_id | int | 员工唯一标识 |
| department | varchar | 所属部门 |
| join_date | date | 入职日期 |
| salary_level | int | 薪酬等级 |
| is_active | bool | 是否在职 |

## 第四章 信息安全

所有员工须遵守信息安全规范，禁止将敏感数据外发至非授权渠道。
口令应定期更换，并启用多因素认证。
